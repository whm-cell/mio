# 图片参考图与蒙版字节预算

```mio-change
{"version":1,"type":"adjustment","section":"3. C1 实施顺序"}
```

2026-11-19 已确认本地修复现有图片执行的内存风险。参考图和 PNG 蒙版单次出现至多 16 MiB，全部出现合计至多 32 MiB，含边界并按出现次数计数；网络并发保持 4。这是保守默认值，不是实测容量结论。

## 范围与实施安排

本期仅修复既有图片准入和未提交执行。C0 已确定字节边界、错误码与原身份恢复义务；C1 在新 HTTP／工具准入的 imageCreate 前返回 413 IMAGE_REFERENCE_LIMIT，历史 ready 任务在任何大对象读取、持久提交意图和上游 POST 前以同码 rejected／done 终结。预算与共享路由结构校验分开，waiting 查询、submitting unknown 判定、持久原件及 materializing 恢复继续沿用原身份。

复用 owner 资产快照、COS 条件长度读取与现有固定并发；保留原请求重放优先、原图字节、引用顺序和蒙版。通用上传与视频限制不变，不增加调度器或预览缩放。

## 验收与规范

按正常 HTTP、工具、服务和恢复入口核对 16／32 MiB 含边界与多一字节、每张合法但总量超限、重复蒙版计数、旧 ready 无读无 POST 且跨 pump／重启不重试；核对合法原字节、顺序、幂等及已提交恢复。继续运行受影响回归、质量／规范审阅和当前完整检查覆盖。

现行行为由[图片 HTTP 契约](../../../../apis/compute.md#post-apiv1computeimages)维护。本变更随同一资源安全维护修复核验；旧[图片能力成果](../../complete/report.md)仅代表其原候选与范围，本轮修改和调试不增加新的业务接受结果。
