# OneLinkAI 集成契约

## 适用范围与接入事实

实际消费者为[用户万联配置](../providers.md)、[目录客户端](../../src/integrations/onelink/models.ts)、[供应商原厂逻辑路由模块](../../src/providers/onelink/router.ts)、[文本传输](../../src/integrations/onelink/chat.ts)/[DSH 适配](../../src/dsh/onelink.ts)以及 A [原厂图片驱动目录](../../src/integrations/onelink/router.ts)。OpenAI Images（`openai-images`）、Volcengine Ark（`volcengine-ark-images`）、Vidu（`vidu-images`）与 Kling（`kling-images`）图片能力均复用同一用户的 OneLink 凭据，首次提交持久冻结已加密凭据快照及版本，实际调用才解密；异步查询使用原任务用户的当前 Key。图片生成与恢复由 A 的 PG 执行记录和专属持久目录承接，不经过 RabbitMQ 或 B；B 不持有 OneLink Key 或图片 RSA 私钥。由单轨数据库路由表 `mio_provider_model_routes` 将用户当前动态目录中已发现的精确 `raw_model_id` 映射到纯原厂协议驱动；W1/W2 文本仍独立于图片和 COS 现场条件。OneLink 文档示例中的 `viduq2`、`kling-v3` 仅作协议参考，不据此生成或改写目录成员；已实证的模型观察见[图片能力成果](../tasks/onelink-image-generation/complete/report.md)，路由架构与待实测模型边界见[万联原厂协议路由 PRD](../tasks/onelink-vendor-routing/prd.md)，未执行真实闭环的型号保持 `unverified`，不能外推已验证结论。视频、语音、音乐及向量执行器仍未装配。范围见[万联 PRD](../tasks/onelink-integration/prd.md)、[万联图片 PRD](../tasks/onelink-image-generation/prd.md)与[万联原厂协议路由 PRD](../tasks/onelink-vendor-routing/prd.md)。公开[模型目录文档](https://docs.onelinkai.cloud/8882392m0)、[Seedream 接入说明](https://docs.onelinkai.cloud/8655248m0)、[Vidu 系列接入说明](https://docs.onelinkai.cloud/8653257m0)、[Kling 系列接入说明](https://docs.onelinkai.cloud/8653497m0)与[文本接入说明](https://docs.onelinkai.cloud/8882610m0)只作协议、字段和映射参考，不建立成员清单；成员与数量仍只取当前用户 Key 成功 GET `/v1/models`。旧源码身份仅在[测试参考](../../tests/providers/fixtures/onelink-legacy-snapshot.ts)保存，不参与生产或构建。

## 必须遵守的约束

- 目标固定为 `https://api.onelinkai.cloud/v1/models`，方法 GET，认证为 Bearer；用户不能提交任意 URL、代理或认证头。不跟随重定向，不自动重试。
- 仅当前用户显式动作解密当前 Key；读取元数据、启动和保存不探测。发现只拉取并校验目录，不执行模型生成或工具调用；Mio 不维护费用逻辑。
- 整个请求/响应体读取期限 10 秒，正文最多 2 MiB，最多 5000 条，单项最多 16 KiB，ID 非空且最多 256 字节、无控制字符。完整校验 data 数组和分页未完成标志；精确重复且全部元数据一致才去重，冲突拒绝整份响应。保留 id 和受限 object/created/owned_by/description，缺值未知；不按名称、前缀或描述推导分类/协议。大小写、点号和套餐后缀保留。
- 认证失败、限流、上游失败、超时、取消、响应格式/体积错误分别返回服务定义的脱敏分类。响应原文、源异常和 Key 不透传；原文及 JSON 解码后的 ID/保存字段均拒绝回显 Key，不能通过 Unicode 转义绕过。关闭取消本域在途请求并等待收敛。
- 图片出站统一固定 `https://api.onelinkai.cloud` origin，拒绝绝对 URL、`..`、`//` 或跨驱动前缀路径：`openai-images` 限 `/v1/`（JSON 生成与 multipart 编辑），`volcengine-ark-images` 限 `/volc/`（如 `POST /volc/api/v3/images/generations`，完全按路由 `paramSpec`/`requestDefaults` 与准入层合成的 `effectiveWatermark` 发送精确 `model`、`prompt`、显式或路由默认 `size`、可选参考图 `image`、`sequential_image_generation` 多图上限至 `maxN=15`、`response_format`、`stream=false` 与 `watermark`，驱动内不内置硬编码默认尺寸或型号分支），结果支持 `data[].b64_json` 或受控公网 HTTPS 下载，经实际文件签名与完整解码核对后写入私有 COS 并登记 owner Asset。
- Volcengine 的 Base64 返回项在请求未指定 `output_format` 且路由未声明固定格式时，从已校验 Base64 的有界前缀识别 PNG、JPEG 或 WebP，交由 A 的独立解码队列继续执行完整图片校验；显式输出格式或固定格式仍按原约束校验。签名识别不证明完整图片有效，未知签名沿既有物化校验处理，不因其转而下载同项 URL。
- Vidu 图片异步（`vidu-images`）限 `/vidu/` 前缀（如 `POST /vidu/ent/v2/reference2image` 与 `GET /vidu/ent/v2/tasks/{task_id}/creations`），Bearer 鉴权；创建发送精确 `model`/`prompt`/参考图 data URI/`resolution`，查询模板必须恰好包含一个 `{task_id}`，导入与受理前共同验证，查询将持久 `task_id` 经 `encodeURIComponent` 代入 `queryPathTemplate`；既存任务保留冻结模板和身份，不改写模板或重新生成。查询回包顶层 `id` 在解释状态前与持久任务 ID 核对，显式非法值或冲突返回 `IMAGE_QUERY_UNKNOWN`；`creations[].id` 属于产物身份。顶层 `id` 缺失时沿既有网关回包兼容，查询仍绑定原持久任务 ID 和冻结路径。完成态先核对 `creations` 张数不超过请求张数，再下载全部结果，超量保持结果未知而不截断。Kling 图片异步（`kling-images`）限 `/kling/` 前缀（支持标准 `/kling/v1/images/generations` 与 Omni `/kling/v1/images/omni-image` 及对应 `{task_id}` 查询路径），Bearer 鉴权；创建发送精确 `model_name`、`prompt`、`n` 及路由允许的 `aspect_ratio`/参考图（按 `requestDefaults.referenceFormat` 显式编码单图 `image` 或数组 `image_list`，不按路径后缀猜测，单图模式超过 1 张立即拒绝），要求 HTTP 2xx、`code === 0` 与合法 `data.task_id` 才认领上游任务；查询在解释状态前要求 `code === 0`、存在字符串 `data.task_id` 且与持久任务 ID 一致，缺失、非法或冲突均返回 `IMAGE_QUERY_UNKNOWN`；核对后，按全小写或全大写封闭状态机（在途 `not_start`/`queued`/`queueing`/`in_progress`/`submitted`/`processing`，失败 `failed`/`failure`，完成 `succeed`/`success`；其余值一律按结果未知关闭）推进，仅在完成态且 `data.task_result.images[].url` 数量不超过请求张数时下载结果，网关计费与完成时间包装字段（如 `final_unit_deduction`、`completed_at`）忽略且不持久化或透传。异步与 URL 结果下载须为公网 HTTPS、无用户信息和非默认端口；A 使用 `ipaddr.js` 2.5.0 分类目标地址，在 `undici` 8.11.2 的实际连接 DNS lookup 中排除非公网地址并保持原 hostname 的 TLS 校验，直接 IP 同样校验，避免检查后再次解析。结果不跟随重定向、不转发 Authorization；限时下载后按实际 PNG/JPEG/WebP 文件签名确定格式，再经完整解码与完整性核对进入私有 COS/Asset。不把 credits、COS key、ETag、Asset ID 或凭据透传。
- 当前用户 Key 显式刷新得到的完整成功目录是成员和数量权威；目录移除阻止新请求，但不是“供应商全局下线”的结论。编排先取得该目录快照，再以 `sourceKind=protocol-reference` 的官方协议/文档依据或 `sourceKind=runtime-observation` 的对应运行观察补充已发现成员的适配；两者都不能创建、补齐或替代目录成员。目录快照、旧 92 项和静态模型清单不是适配来源；没有当前成功目录就停止并保持 pending。成功快照、模型数量、失败尝试、认证阻断和最新开始序号按[供应商规范](../providers.md)持久化，历史 92 项只作迁移参考。根级与非授权 Agent 工具保持默认全拒绝，受控会话生图工具边界沿[DSH 契约](dsh.md)。
- 素材删除使用固定 `POST /volc/openapi?Action=DeleteAssetGroup&Version=2024-01-01`，请求只带本地已绑定的 `Id`。只有已受理的显式确认操作可发出一次组删除。供应商按执行时的组成员整体删除。响应 `Result.Id` 须匹配原目标，官方空回执 `Result:{}` 以同一 `Id` 的精确 `GetAssetGroup` 返回 HTTP 404 `ResourceNotFound` 核实。精确不存在的错误信封只接受缺省或空 Result。矛盾的成功和错误字段视为协议不明，DELETE 的明确拒绝须带合法 Error.Code。恢复沿原操作仅做单组查询。业务授权和状态见[素材 API](../apis/materials.md#post-apiv1materialsgroupsiddelete)。空回执语义与删除影响见[OneLink 素材组删除](https://docs.onelinkai.cloud/451001190e0)。

## 使用经验与适用条件

聊天只允许固定 origin 下经路由校验的相对提交路径：`openai-chat` 要求以 `/v1/` 开头且以 `/chat/completions` 结尾（默认 `/v1/chat/completions`），`anthropic-messages` 固定为 `/v1/messages`（兼容固定 Anthropic SDK 精确的 `?beta=true` 查询），不放行 `..`、`//` 或其他路径/查询。两协议统一 Bearer，SDK x-api-key 被移除，无 ambient/native credential 回退。重定向为 error；SDK及Mio自动 retry 均为0，Anthropic strict-tool 自动降级重发也关闭。鉴权、端点、并发快照不通过共享环境变量切换。正常响应保留公开 PiAi 编码语义；非2xx错误体在进入SDK前替换为固定诊断，观察只取白名单status/requestId/usage/finish/failureCode，不透传原响应/异常。已知HTTP 401/403、408/504、429分别映射鉴权、超时、限流，其他失败不猜测额度或可用性。取消/超时和观察持久化失败分别记录实际状态。

明确声明视觉输入的 chat 路由沿相同固定端点与认证，通过公开 PiAi 编码向 OpenAI 或 Anthropic 协议发送有界图片预览。预算预检和旧图卸载发生在供应商 transport 启动之前；本地失败或卸载重试不登记虚假的上游调用观察。测试替身的线级成功不等于真实视觉模型已验证，现有 chat verified 也不区分文字与图片。

Mio 文本输出上限按路由/适配 `maxOutputTokens`（合法范围 `1..65536`，未配置时默认 `1024`）及 30 秒 HTTP/idle 本地政策执行，未知 supplier context/最大输出不从 SDK 默认大容量推导。普通 check 使用协议替身；独立 conversations-live 经正式用户入口执行真实文本，失败记录实际白名单观察。各协议保留确定性回归，真实验证目标与开发安排沿[万联 PRD](../tasks/onelink-integration/prd.md)与[万联原厂协议路由 PRD](../tasks/onelink-vendor-routing/prd.md)，实际接受范围与限制见对应成果入口。一个目标通过不证明其他目标，未发现或无对应成功观察的目标仍未验证。

旧地址归一化允许其他 host 原样通过，不能作为允许列表复用；旧 TLS 补链、回退和重试没有作为当前必需能力搬入。旧预设及其冲突仅是迁移参考。其余非文本协议路径、错误和生成重试在后续真实消费者出现时另行采纳，不从目录成功推导 Messages、图片、MiniMax 或素材线路可用。

## 验证入口与变更影响

[确定性协议/权限测试](../../tests/providers/providers.test.ts)与[live 审计单测](../../tests/compute/live-image-audit.test.ts)覆盖固定地址、限界、错误与关闭；[独立目录 live 入口](../../tests/providers/providers-live.ts)与[图片场景化 live 入口](../../tests/compute/live-image-loop.ts)（含[单次生成 POST 审计拦截](../../tests/compute/live-image-audit.ts)，支持 `vidu-async`、`kling-async`、`seedream-sync`、`gpt-sync`、`gpt-edit`、`seedream-45-sync`、`seedream-50-lite-sync` 和 `kling-omni-async`）经实际用户 HTTP 和正式打包 Profile 执行目录发现与受限图片闭环（目录无匹配模型时以 `LIVE_MODEL_NOT_FOUND` fail-closed 停止，0 次上游生成 POST）。新增场景目前仅说明脚本支持和离线候选，不代表真实调用成功。普通检查不读取 Key 文件或自动联网。改变目标、鉴权、响应解析、凭据范围或新增协议/副作用时，同步业务/API 规范、对应负向验证和此契约；真实结果与静态、打包通过分别报告。
