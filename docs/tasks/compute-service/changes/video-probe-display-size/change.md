# Worker 视频探测显示尺寸

```mio-change
{"version":1,"type":"fix","section":"通用媒体处理与资产自动派生"}
```

同一视频流通过独立 `video.probe` 或 `media.probe` 探测时，显示宽高使用相同的像素宽高比（SAR）和旋转算法。编码尺寸 320×180、SAR 2:1、旋转 90° 的 MP4 返回 180×640，普通 320×180 的方像素 MP4 返回 320×180。各入口沿用各自的流选择、容器、时长和协议尺寸约束。

用本机 FFmpeg 生成实际 MP4，通过两条探测入口核对结果，并用 1801 秒样本核对通用媒体与独立探测各自的时长界限。含 AAC 音轨、SAR 1:100 的 32×32 AVI 继续支持通用音轨提取，独立视频探测按有效显示尺寸下限拒绝。本轮候选待审阅与接受。
