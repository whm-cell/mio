## 范围与 C0

当前授权覆盖视频整改 Wave 1B 和 1D。实现沿 [V2 的普通生成与恢复](../../prd.md#v2seedancevega-普通生成与恢复)、[视频 HTTP](../../../../apis/compute.md#post-apiv1computevideos)及[资产域数据库](../../../../integrations/postgres.md)契约。两步单独形成候选，隔离行为验证与联合业务接受分别登记。

## C1 实施与验收

- 1B 由资产域批量查本人 ready 引用，首次受理冻结实际对象身份，生成前重新校验并私下签名。沿真实本机 HTTP 与隔离 PG 验证资产不存在、越权、未就绪、类型不符、对象变化、PG 和 COS 故障的精确错误；确认失败零生成 POST，合法引用保留顺序，同请求重放仍返回原任务。旧任务允许按当前真实对象复核，公开快照继续返回业务字段。
- 1D 在下载时同一遍计算 MD5 与 SHA-256，首次物化以一份私有 staging PUT 及一次 COS 条件复制完成。复制使用原探测收据的源 ETag，raw 保留私有 ACL、禁覆盖及视频元数据。已存在 raw 或回执丢失时核对原键、长度、摘要、MIME 和已知复制 ETag，沿同一资产身份恢复。用离线替身覆盖复制源变化、回执丢失、旧收据及原调用方，再核对联合候选的真实 COS 和业务证据。现行要求见 [COS 使用契约](../../../../integrations/cos.md#必须遵守的约束)。
