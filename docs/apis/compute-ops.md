# 计算运维 API

## 本域共同约定

计算服务启用后使用预置实例清单接收遥测。另设 `MIO_COMPUTE_OPS_ENABLED=true` 并配置 `MIO_COMPUTE_OPS_USER_IDS` 才注册运维页面与 API。操作员使用现有 Mio 会话 Cookie。浏览器从同一 A Origin 请求 API；写请求必须携带已配置、完全匹配的 Origin。响应不缓存，错误用统一 JSON 错误体。已登录普通用户得到 403，匿名得到 401。页面跟踪最近一次观测和 A 接收时间，5 秒轮询，超过 15 秒为过期，超过 60 秒为离线。Broker ready/unacknowledged 不采集。

## GET /ops/compute/

身份：Mio 会话 Cookie 和明确的操作员身份。

输入：无查询参数。同源资源固定从 `/ops/compute/app.js` 和 `/ops/compute/styles.css` 读取。

成功：200 返回静态 HTML。脚本读取本域 API。

错误：401 无会话，403 非操作员，404 未启用或路径错误，503 读取不可用。

副作用：无。

## GET /api/v1/ops/compute/summary

身份：Mio 操作员。

输入：无查询参数。

成功：200 返回实例新鲜度计数、在线实例已采样的实际占用、生效与部署硬上限、待槽、HOLD、A 侧转码/媒体待发数和最近一小时每实例事件峰值。

错误：400 查询无效，401 无会话，403 非操作员或 Origin 拒绝，404 未启用，503 查询不可用。

副作用：无。

## GET /api/v1/ops/compute/workers

身份：Mio 操作员。

输入：可选 `limit` 为 1–64，默认 32。可选 `offset` 为 0–64，默认 0。

成功：200 按实例 ID 返回分页，以配置实例为范围。无心跳的实例保留身份及未观测状态。

错误：400 查询无效，401 无会话，403 非操作员或 Origin 拒绝，404 未启用，503 查询不可用。

副作用：无。

## GET /api/v1/ops/compute/workers/{id}

身份：Mio 操作员。

输入：部署清单中的实例 ID。

成功：200 返回最近 boot、心跳与接收时间、实际/生效/硬限、等待、HOLD、活动执行、排空和 desired 状态。过期快照不代表当前进程仍在或已经退出。

错误：401 无会话，403 非操作员或 Origin 拒绝，404 未启用或不存在，503 查询不可用。

副作用：无。

## GET /api/v1/ops/compute/executions

身份：Mio 操作员。

输入：可选 `instanceId`、`jobId`、`state` 及 `limit`。状态支持 `queued`、`active`、`released`、`cancelled`、`unknown`。默认 40，最多 100 条。

成功：200 返回最新优先的执行、协议、资源、归属、任务/attempt/inspection 身份与已知占槽时间。

错误：400 查询无效，401 无会话，403 非操作员或 Origin 拒绝，404 未启用，503 查询不可用。

副作用：无。

## GET /api/v1/ops/compute/executions/{id}

身份：Mio 操作员。

输入：执行 UUID。

成功：200 返回一条执行及至多 1000 条按同 boot sequence 排序的真实阶段/占槽事件。无法确认释放时保留未知，只有实际记录可建立结束时间。同实例同次启动的实际事件缺口若可能改变此前记录的等待状态，该状态也标为未知。缺口和排队事件可以乱序到达。业务结果仍由计算任务接口管理。

错误：401 无会话，403 非操作员或 Origin 拒绝，404 未启用或不存在，503 查询不可用。

副作用：无。

## GET /api/v1/ops/compute/history

身份：Mio 操作员。

输入：可选 `instanceId`、`since`、`until`、`limit`。默认最近 1 小时与 720 点。起止使用 UTC ISO 8601 整秒或毫秒，最大 7 天、1000 点。

成功：200 返回范围内最新 N 点，按时间正序。单实例保留原始样本。汇总取各实例在该时刻之前 15 秒内的最新样本并求和，缺测区间与时钟差分别标记。

错误：400 查询无效，401 无会话，403 非操作员或 Origin 拒绝，404 未启用，503 查询不可用。

副作用：无。

## GET /api/v1/ops/compute/limits

身份：Mio 操作员。

输入：可选 `instanceId`、`limit`。默认 40，最多 100 条。

成功：200 返回最新调限审计，含操作者、前后值、revision、派发后的实际结果和已知确认时间。

错误：400 查询无效，401 无会话，403 非操作员或 Origin 拒绝，404 未启用，503 查询不可用。

副作用：无。

## PUT /api/v1/ops/compute/workers/{id}/limits

身份：Mio 操作员。读取最多 4096 字节、10 秒的 JSON 后复核原会话与操作者。

输入：实例 ID 与 JSON `{expectedRevision,total,encode,probe}`，四项均为非负安全整数。各项上限由此实例部署硬限约束。零表示暂停相应新准入。

成功：202 保存修订并等待 Worker 回执。只有匹配的应用结果表示已生效。离线也可保存已观测过实例的修订并保留待生效。

错误：400 输入无效或超硬限，401 无会话，403 非操作员或 Origin 缺失/拒绝，404 未启用或实例不在清单内，409 revision 冲突或该实例尚不可编辑，413/415/408 请求体错误，503 写入不可用。

副作用：事务写入不可变审计、desired 配置和控制 outbox。B 取得后持久化校验结果，降限让占槽任务继续完成。上调或暂停只改变该实例的新准入。
