## 范围与实施安排

C0 已确认容量、可信分组身份与撤销时效；C1 在 await 前预留全局／未鉴权名额，身份验证后再核对用户名额；按已验证 userId/sessionId 共享每秒调度、五秒预算的 fresh 数据库复核，组内至多一个在途检查。撤销、身份变化、错误或超时关闭对应组，不缓存成功身份，不合并其他会话或用户。

HTTP handler 管理连接清理；subscribe 可接收 AbortSignal，在归属等待后检查取消、在快照等待期间立即移除已安装 listener。失败、断开和 shutdown 释放名额、timer 与 listener；最后成员退出销毁组，旧检查迟到不得影响同 key 新组。保留现有快照缓冲、状态去重、64 KiB 背压和断连后已受理执行继续完成的语义。

## 验收与规范

同一个 handler 错峰建立多个流，核对每秒按会话组而非连接次数复核；并发验证 64／8／256 的上界与释放复用。覆盖不同会话／用户、代表连接退出、撤销／错误／超时、同 key 重建与迟到结果，以及初次鉴权／归属／快照 pending 的取消和 shutdown。保留真实 HTTP 对话、快照竞争、背压与已受理执行回归。
